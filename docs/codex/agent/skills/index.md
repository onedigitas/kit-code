# Agent Router

- CLI commands, tracking, Git/folder mode, and local state: start with `agent/domains/local-tracking-runtime.json`.
- Local HTTP API, SSE, Mini companion, and CORS: start with `agent/domains/local-api-and-mini.json`.
- Rewards, equals ledger, tiers, redemption, and display milestones: start with `agent/domains/reward-ledger.json`.
- Codex/Claude hooks, generated skills, setup prompts, and durable runner: start with `agent/domains/agent-integrations.json`.
- React dashboard, setup gateway, registration, profile storage, and admin view: start with `agent/domains/web-dashboard-experience.json`.
- Coverage and missing tests: start with `agent/registry/test-index.json` and `agent/notes/known-gaps.json`.
