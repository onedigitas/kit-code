# Agent Map

Read order:

1. `agent/registry/domain-index.json`
2. `agent/registry/contract-index.json`
3. `agent/registry/source-index.json`
4. `agent/registry/test-index.json`
5. Relevant detail files under `agent/domains/`, `agent/contracts/`, and `agent/coverage/`
6. `agent/notes/known-gaps.json` and `agent/notes/assumptions.json`
7. `agent/plans/active.json`

Use source files as final authority. Treat this folder as routing metadata for future agents.
